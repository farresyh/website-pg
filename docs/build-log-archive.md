**Admin Panel login flow, end-to-end, 2026-07-24:** the four pieces flagged in the previous session's pointer (below, kept for history) are all built and — unlike everything above, which is proven by `phpunit` — this slice was verified by an actual human logging in through a real browser against a real Herd-served backend. That surfaced three local-environment gotchas worth recording so the next session doesn't rediscover them the hard way:
- `backend/config/cors.php` **did not exist**. Laravel's `HandleCors` middleware only matches paths from `config('cors.paths')`, which resolves to nothing if the app never published this file — so every cross-origin call from `admin/` was silently getting zero CORS headers, not "misconfigured" CORS. Created it explicitly (`allowed_origins` from an `ADMIN_URL` env var, default `http://localhost:3000`; `supports_credentials: false`, since auth is Bearer-token per ADR-009, not cookie-based Sanctum SPA auth — `SANCTUM_STATEFUL_DOMAINS` was a red herring, never actually needed).
- Herd serves this backend at a per-developer domain (e.g. `kedairuncit-backend.test`, from parking the repo folder — not the generic `backend.test` the code defaults to), and **force-redirects `http` → `https`** for secured sites. A redirect on a `POST` silently downgrades to `GET` and drops the body — so `admin/.env.local`'s `NEXT_PUBLIC_API_URL` must point at the `https://` origin directly, never rely on following the redirect.
- Node (unlike the OS/browser) doesn't trust Herd's locally-installed CA by default, so a plain `fetch()` to that `https://*.test` origin from a Route Handler throws `UNABLE_TO_VERIFY_LEAF_SIGNATURE`. Fixed with `NODE_OPTIONS=--use-system-ca` prepended to `admin/package.json`'s `dev` script (Node ≥22 flag, confirmed present on Node v24) — makes Node trust the same system CA store the browser already does, instead of chasing the CA file path by hand.

`admin/.env.local` is gitignored and per-developer (holds each dev's own Herd domain) — not assumed as a shared default anywhere in code.
